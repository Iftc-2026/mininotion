# МиниНоушн

Личный планировщик для GitHub Pages. Откройте сайт и создайте задачу кнопкой «Создать».

Разделы: главная, задачи (таблица и канбан), проекты, календарь, встречи и места, контакты, заметки, корзина и настройки.

Задачи связываются с проектами и контактами. В таблице есть таймер; одновременно работает один таймер. В календаре отображаются незавершённые задачи и встречи. Удалённые записи сохраняются в корзине.

Данные сохраняются в localStorage этого браузера на устройстве. GitHub хранит только код. Облачной синхронизации, авторизации и совместной работы нет. Ответственные не получают приглашений и уведомлений.

Регулярно скачивайте JSON в «Настройки и данные». Для переноса на другое устройство восстановите JSON там. Импорт объединяет записи по ID, значения из файла имеют приоритет; перед импортом скачивается копия текущей базы. CSV экспортирует задачи для Excel.

Заметки редактируются как свободный текст. Блочного редактора Notion, вложений и вложенных страниц в этой версии нет.

Разработка: статический HTML, CSS и JavaScript без сборки. Проверки: `node --check app.js`, `node verify.cjs`. Публикация: Settings → Pages → Deploy from a branch → main → /(root).
