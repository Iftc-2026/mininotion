# МиниНоушн — личное пространство

React + TypeScript + Tailwind CSS, Vite. Чёрно-кремовый интерфейс с боковым редактором и мобильным меню.

## Работа

Задачи, канбан, проекты, контакты, встречи, заметки, календарь, таймер, поиск и корзина. В настройках — профиль, тема, JSON-копии и CSV задач.

Данные остаются в localStorage по прежнему ключу mininotion.v1. ID записей и связи сохранены. Серверной синхронизации и командной работы нет. Повреждённое сохранение не перезаписывается: восстановите исправную JSON-копию в настройках.

## Разработка

npm install
npm test
npm run build
npm run dev

Исходная HTML-точка входа: app.html. Для разработки откройте http://localhost:5173/mininotion/app.html. Корневой index.html — опубликованная production-версия. Vite собирает app.html в dist/index.html, workspace-*.js и workspace-*.css. Для GitHub Pages скопируйте index.html и два workspace-файла из dist в корень репозитория и закоммитьте вместе с исходниками. Pages: main / root. Адрес и origin не меняются, данные пользователей остаются в их браузерах.

Проверка типов: npx tsc --noEmit. Тесты: npm test.

## Облако и новые инструменты

На mininotion.pages.dev доступен вход по логину и паролю. Записи разделены по аккаунтам. Используйте один логин на всех устройствах. После входа старую локальную базу можно добавить в облако кнопкой в настройках. Без входа продолжает работать локальный режим. Для восстановления пароля сохраняйте код, показанный при регистрации: отправки email нет.

Синхронизация отправляет изменения автоматически и проверяет сервер каждые 10 секунд при открытой вкладке, а также при возвращении к ней. Неотправленные изменения сохраняются локально отдельно для каждого аккаунта. Конфликты одного поля сохраняют вторую версию отдельной записью. Максимальный размер облачного пространства — 1,5 МБ. Резервные JSON-копии по-прежнему доступны.

Сервер: Pages advanced mode (_worker.js), привязка DB → mininotion-sync (Cloudflare D1). Vite копирует Worker и _routes.json в dist. Сборка Cloudflare: npm run build -- --base=/. GitHub Pages остаётся локальной статической версией без API.
